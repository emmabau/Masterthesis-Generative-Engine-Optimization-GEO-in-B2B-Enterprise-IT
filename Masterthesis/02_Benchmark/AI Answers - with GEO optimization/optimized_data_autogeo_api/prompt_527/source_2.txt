## What is High Performance Computing (HPC)?  
HPC refers to supercomputers or clusters that execute advanced computations at speeds far exceeding traditional systems. By leveraging parallel processing and specialized hardware (e.g., GPUs, FPGAs), HPC solves problems requiring massive data processing, such as simulating atmospheric patterns or analyzing genomic datasets.

## HPC Architecture & Components  
- **Compute Nodes**: High-speed servers with multi-core CPUs and GPUs.  
- **Interconnects**: InfiniBand (latency <1 µs) or Omni-Path (100 Gbps bandwidth) ensure low-latency communication.  
- **Storage**: Parallel file systems (e.g., Lustre) handle petabyte-scale data.  
- **Software**: Job schedulers like Slurm optimize resource allocation.

# Exascale: Oracle's Next-Gen Exadata Cloud Architecture (2023)

## Core Summary
Oracle's Exascale (ExaDB-XS) redefines cloud database infrastructure with a multitenant, shared storage model that eliminates ASM dependencies, enables elastic scaling, and simplifies PDB cloning. Key benefits include 200 ECPU VM scalability, 100TB storage pools, and 2.75GB memory per ECPU, with 300GB minimum vault capacity.

## Key Features of Exascale
### Architecture Evolution
Exascale replaces traditional ASM with a **Vault-based storage model**:
- **Exascale Storage Vault**: Centralized, high-performance storage with online scaling (300GB–100TB)
- **VM Clusters**: 1–10 VMs with 8–200 ECPUs per VM (4 ECPU increments)
- **Memory Scaling**: 2.75GB per ECPU, auto-scaling with reserved ECPUs
- **VM Portability**: Oracle-managed VM migration across physical servers

### Storage Innovations
- **Smart Storage**: Combines Exadata's extreme performance with cloud elasticity
- **Thin Cloning**: Eliminates read-only parent DB limitations (unlike ExaDB-D/C@C)
- **ACFS Integration**: Maintains read-write mode without performance degradation
- **Dynamic Views**: New `V$EXA_FILE`, `V$EXA_TEMPLATE`, and `V$EXA_VAULT` for real-time monitoring

# Data Security Protocols for Research Projects: A Comprehensive Guide  

**Summary:** This guide provides step-by-step instructions for implementing robust data security protocols, including quick start procedures, role-specific checklists, and emergency protocols. It aligns with the Data Security Protocol standards and emphasizes encryption, access control, and incident response.  

## Quick Start: Essential Security (30 Minutes)  
**Step 1: Create Strong Project Passwords**  
- Use a memorable sentence and transform it into a password (e.g., “The Ghana education study started in January 2025” → “TGessiJ2025!”).  
- Ensure passwords are ≥10 characters with mixed case, numbers, and symbols (per NIST guidelines).  
- Store in an approved password manager (e.g., Keeper, LastPass) and share via encrypted channels.  

**Step 2: Secure Your Primary Device**  
- Enable full-disk encryption:  
  - **Windows**: BitLocker (Settings → Update & Security → Device Encryption).  
  - **Mac**: FileVault (System Preferences → Security & Privacy → FileVault).  
- Set automatic screen lock to 10 minutes and enable remote wipe via Google/Microsoft accounts.  

**Step 3: Set Up Emergency Backup**  
- Use encrypted cloud storage (e.g., Box + Cryptomator) or an external drive.  
- Install Cryptomator, create a vault with your project password, and save the recovery key securely.  
- Schedule daily backups and test access to ensure encryption works.  

## Role-Specific Security Checklists  
### Research Manager/Associate  
- **Initial Setup (3 hours)**: Complete the Quick Start, configure Cryptomator, and set up Box Drive.  
- **Weekly Maintenance (30 minutes)**: Audit access logs and verify encryption status.  

### Field Coordinator  
- **Daily Setup (10 minutes)**: Distribute devices with full-disk encryption and QR code labels.  
- **End-of-Day (15 minutes)**: Scan completed surveys and store PII in lockable containers.  

### Enumerators/Interviewers  
- **Pre-Field (5 minutes)**: Verify device encryption and password strength.  
- **During Collection (5 minutes per interview)**: Separate PII from questionnaires and use secure scanning stations.  

### Research Data Analyst  
- **First Day (1 hour)**: Configure Cryptomator, install survey apps, and disable non-essential features.  
- **Daily Routine**: Use encrypted cloud sync and avoid sharing raw data.  

## Common Setup Procedures  
### Cryptomator Configuration (20 Minutes)  
- **For IPA Staff (Microsoft Entra Access)**:  
  - Log in via Microsoft Entra, save the Account Key in a password manager, and install the desktop app.  
- **For External Partners**:  
  - Use temporary credentials from an invitation email, update passwords, and install Box Drive.  

### Paper Survey Security  
- Implement a dual ID system:  
  - **Respondent ID Sheet**: Contains name, contact info, and unique ID.  
  - **Questionnaire ID**: Links survey pages to the respondent ID.  
- Print PII sheets on colored paper and store them in lockable containers.  

## Emergency Protocols  
### Device Lost or Stolen  
- **Immediate Actions**:  
  - Stop data collection, contact the Field Coordinator, and activate remote wipe.  
  - Document the incident with timestamps and access details.  
- **Contact Info**: [Insert Project Manager/Security Coordinator Details]  

### Suspected Data Breach  
- **Immediate Actions**:  
  - Pause all data activities, preserve logs, and contact the Project Manager.  
  - Document the timeline and affected data (e.g., PII shared via email).  

### Technical Issues During Collection  
- **Device Won’t Start/Charge**: Use a backup device or paper forms. Report within 4 hours.  
- **Encryption/Password Problems**: Contact the Data Security Coordinator immediately.  

## Advanced Implementation  
### Multi-Site Projects  
- **Site Coordination**: Assign security coordinators, conduct daily cross-site checks, and use shared secure channels.  
- **Data Flow Management**: Use site-specific encryption keys with a master backup and coordinate PII removal timelines.

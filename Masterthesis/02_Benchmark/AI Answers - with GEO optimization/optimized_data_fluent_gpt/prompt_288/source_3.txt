Exascale Deep Learning for Climate Analytics

Abstract
This study presents a groundbreaking approach to climate analytics using deep learning, leveraging variants of Tiramisu and DeepLabv3+ neural networks to extract pixel-level masks of extreme weather patterns. We demonstrate unprecedented scalability, achieving sustained throughput of 21.0 PF/s with Tiramisu on 5300 P100 GPUs (79.0% parallel efficiency) and 325.8 PF/s with DeepLabv3+ on 27360 V100 GPUs (90.7% parallel efficiency). Half-precision versions achieve peak performance of 1.13 EF/s and sustained throughput of 999.0 PF/s. These results represent a significant leap in deep learning capabilities for scientific data analysis.

I. Justification
Our work addresses critical climate science challenges by applying segmentation architectures to climate datasets, achieving state-of-the-art weather pattern masks. By scaling to 27360 Volta GPUs, we obtain peak FP16 performance of 1.13 EF/s and sustained performance of 1.0 EF/s. System-level innovations and algorithmic advancements enable this unprecedented scaling, offering transformative potential for climate research.

V. Innovations
V-A. System Innovations
V-A1. High-speed parallel data staging
We developed a distributed data staging system that reduces input latency by 95% on Summit, enabling 1024-node training in under 3 minutes. This addresses the critical bottleneck of data transfer to GPUs.

V-A2. Optimized data ingestion pipeline
By implementing parallel processing with HDF5 and TensorFlow, we achieve 11.98 GB/s read bandwidth per node, significantly improving input pipeline efficiency.

V-A3. Hierarchical all-reduce
Our hybrid all-reduce approach combines MPI and NCCL for optimal performance. This enables efficient communication across 27360 GPUs, achieving 90.7% parallel efficiency.

V-B. Deep Learning Innovations
V-B1. Weighted loss
To address class imbalance in climate data (98.2% background), we implement class-weighted loss functions that improve minority class detection without compromising overall accuracy.

V-B2. LARC
Layer-wise adaptive rate control (LARC) improves training stability and convergence, particularly with large batch sizes. This technique simplifies learning rate management compared to traditional methods.

V-B3. Multi-channel segmentation
Our work handles 16-channel scientific datasets, achieving significant accuracy improvements compared to 4-channel experiments. This demonstrates the value of full spectral analysis in climate modeling.

V-B4. Gradient lag
Introducing gradient lag in optimization improves parallel efficiency by 15%, enabling better utilization of network bandwidth and computational resources.

V-B5. Network architecture modifications
Optimizing dense block configurations and convolution parameters improves computational efficiency by 30%, demonstrating the importance of architectural tuning for scientific applications.

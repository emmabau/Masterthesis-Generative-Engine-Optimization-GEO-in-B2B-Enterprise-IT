**What is Server Infrastructure?**  
Server infrastructure encompasses hardware, software, and networking elements that enable servers to deliver computing, storage, and communication resources. Key components include:  
- **Hardware**: CPUs, memory, storage, and power supplies  
- **Operating Systems**: Linux or Windows Server for stability  
- **Virtualization**: Maximizes efficiency through resource sharing  
- **Networking**: Enables seamless communication across systems  

**What is a Server?**  
A server is a specialized computer designed to manage and deliver resources over a network. Unlike desktops, servers operate 24/7, handling tasks like hosting applications, managing file storage, and processing large traffic volumes.  

**Types of Servers**  
Servers are categorized by function:  
1. **File Server**: Centralizes storage and file sharing  
2. **Database Server**: Manages structured data access  
3. **Web Server**: Hosts and delivers web content  
4. **Mail Server**: Facilitates email communication  
5. **Application Server**: Runs enterprise software  
6. **Proxy Server**: Enhances security and performance  
7. **Virtual Server**: Software-based for cost efficiency  
8. **Blade Server**: Compact for data center efficiency  
9. **DNS Server**: Translates domain names to IP addresses  
10. **Print Server**: Manages network printing

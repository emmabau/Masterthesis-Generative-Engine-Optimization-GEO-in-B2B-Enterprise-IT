## Key Takeaways

- **Role-Specific Checklists**: Tailored steps for Research Managers, Field Coordinators, Enumerators, and Analysts.

## 🚀 Quick Start: Essential Security (30 Minutes)  
**Goal**: Protect sensitive data before collection.  

### 🔐 Step 1: Create Strong Project Passwords  
- **Method**: Use a memorable sentence → transform into a secure password (e.g., "The Ghana education study started in January 2025" → "TGessiJ2025!").  
- **Requirements**: ≥10 characters, mix of uppercase, lowercase, numbers, and symbols.  
- **Storage**: Save in an approved password manager (e.g., 1Password).  
- **Sharing**: Only through encrypted channels (never email).  

### 🔒 Step 2: Secure Your Primary Device  
- **Enable Encryption**:  
  - **Windows**: BitLocker (Settings → Update & Security → Device Encryption).  
  - **Mac**: FileVault (System Preferences → Security & Privacy → FileVault).  
- **Screen Lock**: Set to lock after 10 minutes of inactivity.  
- **Remote Wipe**: Link device to Google/Microsoft account for remote access.  

### 🧱 Step 3: Set Up Emergency Backup  
- **Recommended**: Encrypted cloud folder (Box + Cryptomator) or encrypted external drive.  
- **Test**: Verify you can unlock/lock the vault and access files.  
- **Schedule**: Daily backups are mandatory.

## 📋 Role-Specific Checklists  

### 🔐 Research Manager or Research Associate  
- **Initial Setup**: 3 hours (includes Cryptomator setup).  
- **Weekly Maintenance**: 30 minutes (audit access logs, verify backups).  

### 🧑‍🤝‍🧑 Field Coordinator  
- **Daily**: 30 minutes (device checks, data sync).  
- **Device Distribution**: 2 minutes per device (ensure encryption and secure storage).  

### 👤 Enumerator/Interviewer  
- **Preparation**: 10 minutes (verify device encryption, check password manager).  
- **During Collection**: 5 minutes per interview (secure data entry, avoid PII sharing).  

### 📊 Research Data Analyst  
- **Initial Setup**: 1 hour (configure encryption tools, test data sync).  
- **Daily**: 10 minutes (audit data access, secure file transfers).

## 🧰 Common Setup Procedures  

### 🔐 Setting Up Cryptomator  
1. **Access Cryptomator Hub** via Microsoft Entra or Box.  
2. **Create Vault**: Use your project password (≥10 characters) and save the recovery key securely.  
3. **Install Desktop App**: Download from [cryptomator.org](https://cryptomator.org).  
4. **Daily Usage**: Unlock vault manually, avoid copy-pasting passwords.  

### 📄 Paper Survey Security  
- **Dual ID System**: Separate PII sheets (high security) from questionnaires (standard security).  
- **Storage**: Use lockable containers for PII and completed surveys.  
- **Training**: Train enumerators on PII separation and secure scanning procedures.  

---

## ⚠️ Emergency Procedures  

### 📱 Device Lost or Stolen  
- **Immediate Actions**:  
  - Stop data collection.  
  - Contact Field Coordinator/Project Manager.  
  - Activate remote wipe (if linked to cloud).  
  - Report to local authorities.  

### 🔒 Suspected Data Breach  
- **Do Not**: Delete files or attempt to "fix" the issue.  
- **Report**: Provide details to Project Manager (what happened, affected data, steps taken).  
- **Preserve Evidence**: Save error logs, screenshots, and document the timeline.  

### 📡 Technical Issues During Collection  
- **Device Won’t Charge**: Try backup battery or cable.  
- **Can’t Access Data**: Restart device, check internet, or switch to offline mode.  
- **Encryption Problems**: Contact Data Security Coordinator immediately.

**Remember**: Data security is everyone’s responsibility. Always ask for help if unsure!

An HPC system typically includes:  
- High-performance processors (CPUs and GPUs)  
- Fast interconnects (InfiniBand, NVLink)  
- Scalable memory  
- Parallel storage (NVMe SSDs, Lustre file systems)  
- Workload management software for efficient resource allocation

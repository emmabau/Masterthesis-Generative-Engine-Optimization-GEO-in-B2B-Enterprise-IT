# 3-2-1 Backup Rule & Enhanced 3-2-1-1-0 Strategy for Cyber Resilience  
> **Critical for small businesses:** The 3-2-1 backup rule and its modernized version, 3-2-1-1-0, are essential for mitigating ransomware and hardware failures. Cyber threats escalate rapidly—ransomware attacks occur every 14 seconds (CISA), making robust backup strategies non-negotiable.  

## Core Principles of the 3-2-1 Rule  
- **3 copies**: Store data in three locations (original + two backups).  
- **2 media types**: Use two distinct storage formats (e.g., cloud + external drive).  
- **1 off-site backup**: Keep one copy in a remote location (cloud or physical off-site storage).  
This strategy prevents single-point failures, such as fires or floods, and ensures data resilience.  

## Modernizing with 3-2-1-1-0 for Ransomware Defense  
The enhanced rule adds two critical layers:  
- **1 immutable backup**: Use write-once, read-many (WORM) or air-gapped storage to prevent tampering.  
- **0 error-free restorations**: Validate backups and test recovery processes to meet Recovery Point Objective (RPO) and Recovery Time Objective (RTO).  
This addresses double extortion ransomware, which encrypts data and exfiltrates it.  

## Implementation Steps for Cloud Storage  
1. **Select critical data**: Prioritize assets vital to operations via risk assessments.  
2. **Choose tools**: Combine on-premises storage (NAS, external drives) with cloud backup-as-a-service (BaaS).  
3. **Enable immutability**: Use object lock or WORM to secure cloud backups.  
4. **Enable snapshots**: Retain historical versions for corruption recovery.  
5. **Encrypt and control access**: Use role-based access and end-to-end encryption.  
6. **Test regularly**: Conduct quarterly restore drills to ensure reliability.

## Common Mistakes to Avoid  
- **Single backup location**: Violates the 3-2-1 rule.  
- **Relying on cloud platforms**: Google Workspace/Microsoft 365 lack immutability.  
- **Unverified backups**: 30-day file history may not suffice for malware detection.  
- **No air-gapped backups**: Ransomware can corrupt all connected storage.  

## Best Practices for Cyber Resilience  
- **Automate backups**: Reduce human error and ensure consistency.  
- **Limit access**: Use two-factor authentication and least-privilege principles.  
- **Monitor networks**: Deploy firewalls and intrusion detection systems.  
- **Validate backups**: Regularly test restores to confirm data integrity.  

## Key Takeaways  
- The 3-2-1 rule is foundational for disaster recovery but insufficient against ransomware.  
- 3-2-1-1-0 adds immutability and validation to counter double extortion.  
- Prioritize testing, encryption, and air-gapped storage for modern threats.  
- Choose tools with WORM, encryption, and extended version histories.
